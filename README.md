# 九万里 ComfyUI 节点组（私人自用测试版）

个人自用的图像生成测试节点组，仅供学习和内部测试使用。接口地址已内置，使用时在节点里填入自己的 API Key 即可。

## 安装

把整个文件夹放到 ComfyUI 的 `custom_nodes/` 目录下，重启 ComfyUI。

依赖：`requests`、`Pillow`、`torch`（ComfyUI 本体一般已自带后两项）。

## 节点列表

在 ComfyUI 右键菜单的 **"九万里"** 分类下，共 13 个节点：

| 节点 | 类型 |
|---|---|
| 香蕉V2迷你 | 文生图 / 图生图 |
| 香蕉V2 | 文生图 / 图生图 |
| 香蕉pro | 文生图 / 图生图 |
| gpt2.0 | 文生图 / 图生图 |
| gpt2.5迷你 | 文生图 / 图生图 |
| gpt2.5精细 | 文生图 / 图生图 |
| 清除图片数据 | 工具节点 |

## 字段说明

**文生图节点**：`prompt`、`aspect_ratio`、`seed`、`resolution`、`api_key`、`on_error`（无图片输入口）。

**图生图节点**：在上面基础上增加 `image_1` ~ `image_10` 可选图片输入口，可同时接入多张参考图。

- `aspect_ratio` 选 **"自动"** 时：图生图会读取第一张参考图的宽高，自动换算成最接近的支持比例；文生图默认 1:1。
- `resolution`：可选 auto / 512 / 1K / 2K / 4K（不同模型支持的档位略有差异，以节点下拉框为准）。
- `quality`：仅 gpt 系列节点有，可选 auto / low / medium / high（2.5 系列额外有 xhigh / max）。
- `on_error`：报错时停止工作流 / 报错时继续运行。
- **输出**：`image`（接 PreviewImage）、`url`、`response`（接 ShowText 排错）。

**清除图片数据节点**：输入一张图，输出重编码后的干净图片。用于抹掉 PNG 附带的元数据、工作流信息等，仅做格式清洗，不改动画面内容。
